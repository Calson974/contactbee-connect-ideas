# BoostWhats

A modern web application for managing and sharing contact information with a focus on WhatsApp integration.

## Features

- 📱 **Contact Management**: Easily manage and organize your contacts
- 📅 **vCard Generation**: Generate vCard files for easy contact sharing
- 💬 **WhatsApp Integration**: Seamless sharing via WhatsApp
- 🎨 **Modern UI**: Clean, responsive design with dark mode support
- ⚡ **Fast Performance**: Built with Vite for optimal performance

## Tech Stack

- ⚛️ React 18 with TypeScript
- 🎨 Tailwind CSS for styling
- 🔄 React Query for data fetching
- 🗃️ Supabase for backend services
- 🚀 Vite for build tooling
